# Check implementation against spec

1. Read the linked Issue, current diff, and every current requirement document.
2. Map each acceptance criterion and task to implementation and test evidence.
3. Identify missing behavior, mismatches, extra scope, and stale documentation.
4. Verify paths, commands, and claims against the current checkout.
5. Report findings by severity with exact locations and the smallest corrective
   action.

This is a read-only review. Do not modify, approve, merge, or close work unless
the caller separately asks and authorizes those actions.
