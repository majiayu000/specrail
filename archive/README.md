# Historical archive

This directory preserves earlier SpecRail project history.

- `specs/` contains the original issue-linked product, technical, and task
  documents.
- `LEGACY_CHANGELOG.md` contains the earlier release history.

The files are retained verbatim for provenance. They are read-only historical
material: active skills, tools, CI, and development decisions must not consume
them as current requirements or validation input. Corrections should be made
in current documentation, not by rewriting this archive.
